# Python Game Education

Projeto simples para estudar Python de forma interativa pelo navegador.

## Como usar

Abra `index.html` no navegador ou acesse a versão publicada do projeto.

## Conteúdo

- fundamentos de Python;
- exercícios rápidos;
- perguntas de múltipla escolha;
- progresso das lições;
- revisão dos conteúdos concluídos.

## Estrutura

- `index.html` — página principal;
- `style.css` — visual do projeto;
- `script.js` — funcionamento da aplicação;
- `data/` — conteúdo das aulas.
